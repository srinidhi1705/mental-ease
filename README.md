# 🧠 MentalEase – AI-Based Mental Health Support System

## 📌 Overview

MentalEase is a digital mental health and psychological support system designed specifically for students. It provides a safe, private, and accessible platform where users can express their thoughts, track their emotions, and receive AI-driven support.

The system focuses on early emotional assistance and continuous mental health monitoring using Artificial Intelligence.

---

## 🚀 Features

* 🤖 AI Chatbot for real-time emotional support
* 📊 Mood Tracking to monitor emotional patterns
* 📝 Journaling for self-expression and reflection
* 🔐 Secure Authentication for user privacy

---

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend:** Python (FastAPI)
* **AI Integration:** Gemini API

---

## ⚙️ How to Run the Project

### 1. Clone the Repository

```
git clone https://github.com/srinidhi1705/mental-ease.git
cd mental-ease
```

### 2. Run Frontend

```
npm install
npm start
```

Open: [http://localhost:3000](http://localhost:3000)

### 3. Run Backend

```
cd backend
pip install fastapi uvicorn python-dotenv google-generativeai
python main.py
```
